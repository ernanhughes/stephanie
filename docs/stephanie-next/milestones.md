## Milestone delivery checklist

Every implementation milestone must state reused code, exact contract, data/migration change, deterministic and live tests, demonstration, known limits, rollback, and prerequisite IDs. STN03 preserves ordinary SIS chat and introduces an explicit, separately gated Worker action. STN04 is a live OpenCode execution but is still `COMPLETED_UNVERIFIED`; STN05 does not treat it as accepted until a human records that decision. External runtime demonstrations remain separate from model-independent tests.
