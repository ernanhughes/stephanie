# Frozen experiment protocol

Run `python -m stephanie.improvement se2-freeze` before any generation. This writes `data/stephanie_evolution02/frozen-manifest.json`, binding task/history/rubric hashes, fixed task order, arms, local model identity, limits and evaluator version. The fixed sample is eight tasks × A/B/C = 24 attempted calls. No retries or setting changes. Run `se2-run` once; it refuses an existing result file. A is current evidence only; B calls `ImprovementEngine.retrieve_experience` with lexical ranking and limit 3; C includes all eight reviewed cases. All arms share Ollama `ornith-1.5:9b` (local tag ID `e5df7dcdd8a2` at freeze), temperature 0, output cap 240 and timeout 120s.

The study uses actual shared `ai.inference.InferenceService.generate_structured`. Inputs, memory IDs, errors, prompt character counts and latency are retained. All 24 outputs failed structured parsing and did not return `ReasoningResult` to the caller, so generation token counts and dollar-cost observations are unavailable; they are unknown, not zero. B/C receive more context, so memory relevance is confounded with information/token quantity; no context-matched neutral arm is included. The rubric is SHA-bound and opened only by the post-generation evaluation command.
