# S6 — Offline Harness compatibility

Stephanie includes a small import adapter for sanitized H3Q/H4/H5/H6 evidence. It preserves distinctions among synthetic fixtures, local single samples, isolated scripted execution, Work Envelope correlation, independent evaluation, and human acceptance. Source document SHA-256 values are pinned in `harness_fixtures.json` and the evidence register.

H6 is not assigned an independent evaluation it does not have. Mission source, services, ports, and databases were read-only and untouched. The adapter is an offline evidence mapping, not an operational Mission/Worker integration.
