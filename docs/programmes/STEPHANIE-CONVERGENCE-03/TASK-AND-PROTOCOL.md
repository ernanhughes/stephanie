# Task and Frozen Protocol

Selected task: Worker structured JSON output handling, comparing `structured.v1` against `adaptive.v1` with the existing deterministic `json-fence.v1` transform. This is an actual bounded Worker mechanism and uses exact-output evaluation; no new intelligence framework was introduced.

Before freeze, a once-only shared AI call generates the structured hypothesis from a sanitized Worker strategy source summary. The call uses the existing `InferenceService`, a local Ollama route, and a one-call budget; raw/provider/usage/failure details are retained in `ai/ai-executions.json`. The returned hypothesis must cite the supplied Worker evidence ID. `ai-hypothesis.json` records the parsed hypothesis and digest; freeze binds that digest and evidence identity. The protected exact-answer evaluator is never included in AI or Worker context. Retry is prohibited once the AI evidence artifact exists.

Stephanie freezes the baseline and candidate, evaluator, protocol, and Worker source identity before execution. Their digests and the strategy allowlist are recorded in `frozen-protocol.json`; the evaluator is separately stored in `frozen-evaluator.json`. Candidate mutation outside the allowlist is rejected before a Worker request. Baseline and candidate retain paired task identifiers. Evaluator content is absent from Worker request context.

Cohorts: C1 improvement control (3 per arm), C2 no-benefit control (3 per arm), C3 semantic regression control (3 per arm), C4 insufficient evidence (1 per arm). C5 is a separate extra-compute confound control (3 per arm): it compares `structured.v1` with `corrective.v1`, which can make a second invocation. C5 is not an efficacy comparison of the frozen `adaptive.v1/json-fence.v1` candidate. C6 records a scripted Worker provider failure; C7 attempts a disallowed candidate and is rejected locally. These are deterministic fixture outcomes, not claims about general model quality.

The first orchestration attempt completed 27 deterministic Worker requests but failed while serializing a missing source-commit field. It is retained at `data/stephanie_convergence03/run-attempt.json`. The first successful artifact set also revealed C5 request limits of 128 tokens while the frozen protocol said 64. That historical root is preserved and C5 is not considered qualified there. The protocol was corrected to consistently declare 128 tokens and frozen again in a new root, `data/stephanie_convergence03_corrected/`; all 27 deterministic requests were executed there. No model calls were made for this correction.
