# SC4 governance and outcome contracts

SC4 preserves the existing Mission ownership boundary. The bounded SC4A fixture path lets Mission request a deterministic investigation, revise the same Work Corrective proposal for a separately reviewed frozen experiment, reserve an active Work Envelope, and dispatch the existing Stephanie SC3 runner. Actual Worker execution and Praxis comparison remain Stephanie-owned. Experiment approval does not authorize model inference, formal acceptance, objective completion, or production promotion. The browser workflow and operational activation remain unqualified.

The read-only artifact projection checks the SC3 candidate, protocol, hypothesis, results, experience, and trace relationships. It suppresses raw response content. The generated projection manifest is a post-hoc consistency snapshot, not a signature or trusted attestation.

SC4 implements that authority and execution contract only for the exact frozen deterministic JSON-fence fixture. It does not establish a general experiment service or qualified cancellation path, and it does not provide formal candidate acceptance, objective completion, or production promotion. Those are distinct Mission outcomes and remain outside this bounded fixture integration.
