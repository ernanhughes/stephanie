# SC4 user guide

Open Mission Control's **Improvement** navigation item (route `/improvement`) in a build that includes SC4. The page shows Mission work records and a historical SC3 evidence projection across Overview, Opportunities, Experiments, Experience, and Configuration.

Selecting an existing open finding can create a `REQUEST_USER_DECISION` corrective proposal. This records an investigation request; it does not approve or run an experiment. The experiments view is informational. Do not interpret historical SC3 evidence as a live SC4 run.

The running local Mission service was not upgraded and the new API route currently returns 404. This workspace is not operationally activated.
